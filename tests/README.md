# MINICRAFT 完整回归测试

此目录保存项目的持久化回归测试。测试不使用玩家存档目录；服务器迁移、HTTP 和消息测试均使用临时目录，运行结束后自动清理。

## 一键运行

### Windows

双击：

```text
运行完整回归测试.bat
```

### Linux / macOS

```bash
./tests/run_regression.sh
```

### 通用方式

在 `minicraft` 项目目录执行：

```bash
python3 tests/run_all.py
```

需要：

- Python 3.10+
- `requirements.txt` 中的 `aiohttp`
- Node.js 18+

## 文件说明

```text
tests/
├── client_regression.js          客户端纯逻辑回归测试
├── project_server_regression.py  项目结构、备份和服务器回归测试
├── run_all.py                    跨平台总入口
├── run_regression.sh             Linux/macOS入口
└── 运行完整回归测试.bat          Windows入口
```

## 当前覆盖范围

### 客户端

1. 20种轨道的固定顺序、尺寸和旧存档索引兼容。
2. 13套预定义模板在四个旋转方向上的占用与接口连通，包含双桥、感应转盘与蛇形探险线。
3. 旋转轨四向出口、中心转向路径、方向标签、寻路、图标和 `Shift+8` 快捷键。
4. 旋转轨交互、列车/车厢占用锁定，以及车站寻路自动预转向。
5. 感应轨计数、报站提示、动态脉冲、Shift+E目标绑定、岔道/转盘触发和联机主机权限。
6. 线路保存为个人蓝图、状态清理、持久化、重复摆放、8份上限和删除。
7. 二次确认整线拆除、列车占用保护、库存返还和Z整线恢复。
8. 车站1/2/4/8秒停靠时刻、Shift+E时长、Ctrl+E巡线开关、↑↓巡线顺序和蓝图保存。
9. 模板幽灵预览、旋转、位置被占用后的迁移、确认、库存和整套撤销记录。
10. 自动闭塞信号的方向、保护区间追踪、3D引导、列车占用、行人与净空检测。
11. 直轨、弯轨、坡道、升降桥、旋转轨的可站立表面及轨道空间索引。
12. 本地/远程行人检测、前向距离、主/附加列车制动、信号联动和乘客排除。
13. 木质车库自动停车、直接通过、信号保护和主/附加列车支持。
14. 20种轨道图标、数字快捷映射和退出时恢复原积木。
15. 道口栏杆拦住道路而不侵入火车通行空间。
16. 水、玻璃和轨道接触面的遮挡规则。
17. 备份JSON校验的有效与损坏输入。
18. 客户端主脚本 `node --check` 语法检查。

### 项目与Python服务器

1. 拆分后的 `index.html`、CSS、JS文件结构、资源版本和跨文件DOM引用。
2. JSON/gzip备份格式往返。
3. 旧64×64世界迁移至128×128和10层地下，保留建筑与已挖浅层洞。
4. 新基岩、外部地形、湖泊、道路和原子存档。
5. 单方块/批量方块坐标边界、512条批量上限和建造权限。
6. 猫命令不受建造权限影响。
7. 联机玩家乘车状态转发，避免远程乘客触发行人刹车。
8. `/`、`/index.html`、`/assets/`、`/api/rooms` HTTP路由与路径保护。
9. 8人上限、32MB消息上限、房间名规则和中文JSON。
10. `server.py` 的 Python 编译检查。

## 增加新功能时

- 新增轨道类型必须追加到 `TRACK_SHAPES` 末尾，不可改变旧索引。
- 新增模板必须通过四方向无重叠和无断口测试。
- 修改轨道路径、坡度或站立物理时，应在 `client_regression.js` 中补充相应断言。
- 修改服务器坐标、迁移或消息处理时，应在 `project_server_regression.py` 中补充边界测试。
- 提交或发布前运行 `python3 tests/run_all.py`。

这些测试以逻辑、格式和服务器集成为主，不替代真实浏览器中的视觉检查、手柄/触屏测试和多人跨网络测试。
