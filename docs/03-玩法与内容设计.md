# 03 · 玩法与内容设计

> 本文覆盖游戏内容层：叙事、任务与成就、轻生存要素、经济与制作、小屋互动、
> 钓鱼、伙伴猫、装修模式，以及贯穿其中的数值设计。
> 轨道与列车作为核心系统单独成篇（见 04）。

## 1. 叙事设计：「归家的灯火」

### 1.1 主题与基调

整个内容层围绕一个温柔的母题——**回家**。奶奶留下小屋与信件，玩家作为归人重新认识
这个世界；探索的终点不是打败什么，而是「把故事带回家」。文案刻意保持低压力、生活化。

### 1.2 内容载体

| 载体 | 数量 | 触发 |
| --- | --- | --- |
| 故事章节（`storyEntries`） | 9 章 | 按进度解锁：开局第 0 章；进屋/读书/开宝箱/结识猫/发现矿洞/营地/冰屋各解锁一章；集齐星晶与全部发现解锁终章 |
| 每日信件（`dailyLetters`） | 7 封循环 | 每个新游戏日，门廊信箱升起旗子（`mailDay < dayCount`），阅读后收起 |
| 旅行手记 | 书架随机 5 条小贴士 | 对书架按 E |
| 成就 | 15 项 | 见 §3 |

### 1.3 解锁节奏

故事解锁与**空间探索**绑定而非任务清单：玩家走到哪、摸到哪，故事就讲到哪。
`unlockStory()` 在暂停时入队（`storyQueue`），逐篇弹出阅读，避免刷屏。

## 2. 主线任务链（`questStage`）

| 阶段 | 条件 | 引导文案 | 进度 |
| --- | --- | --- | --- |
| 0 | 开局 | 找到木门，按 E 打开它 | 12% |
| 1 | 开门 | 门开了！走进小屋看看 | 42% |
| 2 | 进入小屋（区域判定） | 找到屋内角落的宝箱，按 E 开启 | 72% |
| 3 | 开启宝箱 | 主线完成 · 星晶 x/3 · 矿○/营○/雪○ | 100% |
| 终局 | 星晶 3 + 三地标全发现 | 全部探索完成 · 你是方块世界冒险家！ | — |

设计意图：前 3 步在 5 分钟内完成，建立「这是家」的归属感；终局收集把玩家引向
铁路（远距离移动的最好理由）。

## 4. 轻生存要素（默认关闭）

- **和平模式为默认**（`adventureMode=false`）：无怪物、无伤害，专注探索建造。
  暂停菜单可切「夜间生物：开」。
- **史莱姆**（7 只，固定巢穴坐标）：仅夜间（19:00–5:36）且冒险模式激活；
  HP 3，接触伤害 1（1.15s 无敌帧 + 击退）；击退掉落凝胶 + 草方块，白天原地复活。
- **战斗**：空手伤害 1（冷却 0.46s），持石剑伤害 2（冷却 0.28s）；
  攻击判定为视线方向 4 格内的球体近似（含墙体遮挡检查）。
- **生命与恢复**：上限 5；睡觉 / 凝胶药水（+5）/ 篝火烤鱼（+2）恢复；归零后
  在清晨的营地重生（世界不重置，时间拨回 7:00）。
- **设计意图**：生存是「调味」而非主菜——数值上永远打不死熟练玩家，但夜晚因此有了重量。

## 5. 经济与制作

### 5.1 材料与库存

- 快捷栏 11 种物品（`hotbarOrder`：草方块/木板/石头/砖块/灯笼/石剑/木门/树叶/玻璃/轨道/水）。
- 初始各 1000、上限 9999（`itemCap`）——**刻意宽裕**：本作建造不设资源 grind，
  材料计数更多是成就与工坊的输入。
- **方块 ↔ 物品 ID 映射**（部分 ID 在两个命名空间重载）：

| 物品 | 放置成的方块 | 挖掘掉落来源 |
| --- | --- | --- |
| 木门(31) | 木门方块(8，占 2 格) | 拆任何门 |
| 树叶(32) | 树叶(6) | 挖树叶 |
| 灯笼(5) | 灯笼(9，可开关光源) | 挖灯笼 |
| 水方块(38) | 水(18) | 挖水 |
| 凝胶(7)/鲜鱼(8) | 不可放置 | 击退史莱姆 / 钓鱼 |

其余物品 ID=方块 ID；原木(5)/书架(24) 等挖出木板(2)，铜矿(20) 挖出石料×2，基岩不可挖。

### 5.2 工坊配方（6 种）

| 配方 | 输入 | 输出 | 备注 |
| --- | --- | --- | --- |
| 温暖灯笼 | 木板×3 + 石头×2 | 灯笼×1 | 光源 |
| 烧制砖块 | 石头×3 | 砖块×2 | 建材 |
| 石剑 | 木板×3 + 石头×2 | 石剑×1 | 唯一持有（`unique`） |
| 石镐 | 木板×3 + 石头×3 | 永久被动 | 岩石类挖掘提速 48% |
| 凝胶药水 | 凝胶×2 + 草方块×1 | 生命全满 | 仅缺血时可用 |
| 篝火烤鱼 | 鲜鱼×1 + 木板×1 | 生命 +2 | 即时消耗型 |

- **材料来源合并**：小屋内自动并入储物箱库存（`materialCount`），鼓励「把材料放家里」。
- 石剑/石镐是永久装备（不占快捷栏数量），`updateHeldItem()` 切换手部模型显示。

### 5.3 储物箱

开启宝箱后（方块 16→19），屋内可打开储物箱面板：13 种物品背包/箱内双向整存整取，
每种箱内上限 9999。存入是工坊可用材料的一部分（见上）。

## 6. 小屋互动（家的细节）

| 互动 | 触发 | 行为 |
| --- | --- | --- |
| 木门 | 距离 3.15 内按 E | 开合动画（旋转角插值），玩家站门内禁止关门 |
| 壁炉 | 距离 2.35 内按 E | 点燃/熄灭；点燃时炉膛发光 + 点光源 + 烟囱冒烟 |
| 旅行手记 | 对书架按 E | 随机小贴士；首次解锁故事第 2 章 |
| 信箱 | 对信箱按 E | 阅读今日信件；新信时旗子升起（网格重建反映） |
| 木梯 | 对梯子按 E | 一楼 ⇄ 阁楼瞬移；首次解锁「阁楼时光」 |
| 睡觉 | 夜间（18:30–6:12）靠近任意床 | 黑屏过渡 → 7:00 新一天：回满血、天气放晴、鱼群繁殖、天数+1 |
| 菜园 | 距离 3.4 内按 E | 收获 8 格作物 → 草方块；40s 后自动重种 |
| 方块羊 | 靠近或点击 | 首次赠送草方块×2 + 成就；之后闲聊 |
| 灯笼 | 对准按 E | 逐个开/关（状态存 `blockLightStates`，影响点光源） |

**区域判定**（`isInHouse/isInCave/isInCamp/isInIgloo`）使用硬编码包围盒，
与世界生成位置强耦合——修改生成布局时必须同步这些判定（回归测试有覆盖）。

## 7. 钓鱼与水域

- **三处水域**：林间池塘 / 南方湖泊 / 沙漠绿洲，各自维护鱼群数量 0–30（`fishPopulations`）。
- **放养与繁殖**：背包鲜鱼可放养（1/10 条），`≥2` 条每天自然 +1 至 30 上限；可收回。
- **钓鱼流程**（状态机 `fishingState`）：
  1. 距水边 ≤5.2 按 E 抛竿 → 等待（有鱼 0.8–2.2s，无鱼 2.2–5s）；
  2. 浮标下沉（1.55s 窗口）→ 按 E 收线成功；超时鱼逃走。
- **可见反馈**：鱼群按数量在水面游弋（颜色/相位各异）、水生植物、气泡、涟漪；
  下雨天涟漪加密。钓鱼距离超 5.8 自动收线。
- **产出**：鲜鱼 → 喂猫 / 烤鱼；钓起时扣减该水域鱼群（可持续渔业）。

## 8. 伙伴猫「橘子」

| 机制 | 设计 |
| --- | --- |
| 结识 | 门廊边按 E 交朋友（亲密度 1，解锁故事与成就） |
| 亲密度 0–5 | 摸摸（30s 冷却 +1）/ 喂鱼（+2）/ 玩毛线球（+1）；满级换金色项圈 + 成就 + 每日礼物 |
| 行为模式 | 跟随（夜间在屋内改为回垫）/ 原地等待 / 回小屋软垫；命令面板或 E 交互切换 |
| 玩耍 | 扔毛线球（10s 正弦轨迹追逐动画），结束回到身边 |
| 乘车 | 主列车有客车厢时可让猫坐车厢顶，随车巡游（联机下经 `catRide` 广播） |
| 礼物 | 亲密度满后每天一次：草方块×4 / 木板×3 / 鲜鱼 / 石头×2 按天数轮换 |
| 渲染 | 盒件组装的猫模型：坐/走/睡三姿态 + 尾巴摆动 + 影子 |

移动采用「目标点 + 逐步逼近 + 阻挡检测」（`catBlocked`），可穿过非固体、绕不开时
距离 >18 格直接传送（防走丢）。夜间在屋内会自主回垫睡觉。

## 9. 装修模式（B 键）

### 9.1 交互模型

2D 平面图编辑器（`decorGrid` canvas，11×12 格对应小屋一层与阁楼）+ 3D 实时预览。
仅在小屋内可开启（`isInHouse` 判定）；放置合法性 = 网格空位 + 无实心方块 + 不压玩家。

### 9.2 家具目录（16 种）

木椅 / 圆桌 / 软沙发 / 储物柜 / 落地灯 / 盆栽 / 花纹地毯 / 星晶展台 / 长木凳 /
木屏风 / 装饰画 / 烛台 / 单人床 / 双人床 / 四柱床 / 双层床。
床类占地 1×3（双人 2×3，随 45° 旋转适配朝向），其余 1×1；
落地灯与烛台为**可开关点光源**（影响渲染与 shader 灯列表）。

### 9.3 编辑能力

| 能力 | 说明 |
| --- | --- |
| 变换 | 45° 旋转（床 90° 对齐）、4 档缩放（75–150%）、0.1 格微调（ox/oz）、升降 0–3 格 |
| 吸附 | 贴齐格点 / 吸附最近墙面（装饰画自动抬高）/ 吸附顶面 |
| 批量 | 多选模式（Shift 点击）、批量旋转/染色/缩放/删除；镜像朝向 |
| 主题 | 每层独立的地板主题 ×6、墙面主题 ×6（薄贴面渲染 `drawRoomThemes`） |
| 预设 | 一键布置阅读角 / 温馨客厅 / 舒适卧室（自动寻找连续空位） |
| 历史 | 撤销/重做 30 步（JSON 快照 `decorSnapshot`）；布局保存/恢复（一楼+阁楼） |
| 上限 | 60 件；清空本层需二次确认 |

家具参与玩家碰撞（`decorCollides`，按类型半径/高度近似，床按占用格），
床同时是有效睡觉点（`nearestDecorBed`）。

## 10. 个性化

6 套服装配色（上衣/裤/披风三元组）、左/右肩位、挥手表情（G 键，2.2s 动画）。
选择存档并在联机时随 `player` 消息广播给其他玩家。

## 11. 数值设计汇总

| 系统 | 关键数值 |
| --- | --- |
| 时间 | 一天 ≈ 369s；睡觉窗口 18:30–6:12；快速旅行仅白天 6:00–18:30 |
| 天气 | 雨 28–50s / 晴 55–100s |
| 生命 | 上限 5；无敌帧 1.15s；重生回满 |
| 移动 | 走 3.25 / 跑 5 / 飞 5(8)；跳跃 1.17 格 |
| 材料 | 初始 1000 / 上限 9999 |
| 钓鱼 | 鱼群 0–30；咬钩窗口 1.55s |
| 猫 | 亲密度 0–5；摸 30s CD；礼物每日 1 次 |
| 菜园 | 收获 8 格草方块；重种 40s |
| 快速旅行 | 4 个已发现地标；夜间禁用（鼓励睡觉/铁路） |

**数值总原则**：所有资源再生都挂在「天数」上（鱼、菜园、信、礼物），
让「在小屋睡一觉」成为有收益的节奏点，与叙事互相强化。
