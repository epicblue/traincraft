# 02 · 客户端与渲染设计

> 本文覆盖 `assets/minicraft.js` 中与「画面呈现、世界表达、操作手感」相关的设计：
> 渲染管线、网格生成、相机与物理、世界生成、环境模拟、音效、HUD 与输入。

## 1. 画面分层结构

页面由多个固定定位的全屏层叠加（z-index 从低到高）：

| 层 | 元素 | 内容 |
| --- | --- | --- |
| 0 | `#starCanvas`（2D） | 星空：230 颗程序化星点、银河光带、每 37s 一颗流星；日出/雨天淡出 |
| 0 | `#skyOrb`（DOM） | 日/月圆盘，沿屏幕按 `worldTime` 走弧线，夜间变月色 |
| 1 | `#game`（WebGL） | 3D 世界主画面 |
| 2 | `#weatherCanvas`（2D） | 雨/雪粒子（避雨时隐藏）；`#vignette` 暗角 |
| 3 | `#hud`（DOM） | 品牌、任务卡、状态条、导航、小地图、热键栏、准星、提示、toast |
| 4 | `#damage` | 受伤红闪 |
| 5+ | `.touch-ui`、聊天、各功能面板（z-index 6–40） | 触屏控件、快捷聊天、面板体系 |

天空颜色本身画在 `body` 的 CSS 渐变背景上（WebGL canvas 透明 `alpha:true`），
由 `updateSky()` 按时间/天气/晨昏动态计算两端色值。**这样做的好处**：天空零绘制成本，
且 CSS `transition` 免费获得平滑过渡。

## 2. 渲染管线

### 2.1 着色器（唯一程序）

- **顶点着色器**：`aPos`（vec3）+ `aColor`（vec3），乘 `uMVP`；水面模式下顶点 y 随
  `uTime` 正弦波动（波浪顶点位移）。
- **片元着色器**统一处理：
  - **距离雾**：`smoothstep(uFogNear, uFogFar, dist)` 混入 `uFog` 天空色；
  - **点光源**：最多 8 盏（`uLamps[8]` + `uLampCount`），半径 10 格，带 `uTime` 闪烁；
    光源候选 = 灯笼 + 轨道灯 + 隧道灯 + 装修灯 + 列车头灯，按到相机距离**排序取前 8**；
  - **水面着色**（`uWaterMode==1`）：法线扰动 + 菲涅尔 + 太阳高光 + 深/浅水混合 +
    透明度随视角变化（`outAlpha = .64 + fresnel*.50`）；
  - **特殊水感**（`uWaterMode==2`）：水面涟漪线与水生植物使用的水波着色分支；
  - **环境光**：`uLight`（天空亮度 0.26–1.0，洞内 ×0.42，雨天 ×0.72）与点光源取最大值。

### 2.2 缓冲组织

| 缓冲 | 内容 | 更新时机 |
| --- | --- | --- |
| `chunkMeshes[]` | 世界静态几何，按 16×16 水平块分桶，每块一个 VBO（顶点格式 24B：pos3+color3） | `rebuildMesh()`（方块/轨道结构变化时） |
| `trackBuffer` | 全部轨道积木的程序化网格 | 同上（轨道属于静态几何） |
| `glassBuffer` | 玻璃面（面内缩 0.0015，半透明） | 同上 |
| `waterBuffer` / `shoreBuffer` | 水面（面内缩 0.002）与岸边浪花线 | 同上 |
| `emissiveBuffer` | 灯笼等自发光体（按 `uLight=1` 绘制） | 同上 |
| `entityBuffer` / `lineBuffer` | 全部动态实体与线框/引导线 | 每帧 `bufferData(DYNAMIC_DRAW)` |

**绘制顺序**（`render()`）：分块世界 → 轨道 → 寻路/信号引导线 → 模板幽灵 → 放置幽灵 →
接口提示 → 感应链路/脉冲 → 信号灯 → 升降桥 → 道口栏杆 → 列车 → 自发光 → 鱼群 →
水面 → 浪花线 → 水生植物 → 涟漪 → 门 → 史莱姆 → 浮标 → 毛线球 → 猫 → 房间主题 →
家具 → 远端玩家 → 本地玩家 → 炊烟 → 氛围生物（萤火虫/蝴蝶）→ 玻璃 → 远端目标框 →
本地目标框 → 玩家名标签（DOM）。
透明物统一**后画 + `depthMask(false)`**，利用绘制顺序近似排序，避免 OIT 复杂度。

### 2.3 性能设计

- **分块剔除**：只绘制距相机 `renderDistance + 13` 内的块；`drawnChunks` 计数显示在 FPS 徽标。
- **三档画质**（`applyGraphics()`）：流畅/均衡/精美 → DPR 1 / 1.35 / 1.75，
  渲染距离 32 / 48 / 72，天气粒子上限 42 / 80 / 120；氛围生物与鱼群数量同档联动。
- **雾距联动**：`uFogNear = max(18, rd×.55)`，`uFogFar = rd + 16`，剔除边界藏在雾外。
- **节流**：小地图每 4 帧重绘；FPS 统计每 600ms；远端玩家标签仅 45 格内且在视锥内渲染。

## 3. 世界数据与网格生成

### 3.1 存储

```js
world = Map<"x,y,z", blockId>        // 稀疏：空气不存
get(x,y,z) → 0 | id
set(x,y,z,t) → 写 Map + 标脏 + （联机时）queueNetBlock(...)
```

`insideWorld(x,z)` 限制建造边界为 1..126（边界树篱外圈不可建）。

### 3.2 `rebuildMesh()` 流程

1. 先 `rebuildTrackGraph()` 重建轨道三索引（见 04）；
2. 遍历 `world`，每方块按 `floor(x/16), floor(z/16)` 分桶；
3. 逐面剔除：`occludesCubeFace(邻居)` 为真则跳过该面（非整立方体如门/栅栏不剔邻居）；
4. 特殊方块走专属网格生成器（见下表），普通方块用 `blockColor()` 程序化配色 + 面亮度；
5. 水面额外生成岸边浪花线（相邻无水的边）；
6. 轨道积木统一由 `pushTrackPiece()` 按 shape 程序化生成（木色基底 + 凹槽 + 功能件）。

### 3.3 程序化配色（`blockColor`）

基色调色板 `palette[id] → [r,g,b]`，叠加：
面亮度 `[.78,.70,1.03,.55,.88,.82]`（顶亮底暗）、坐标微抖动（±2.4% 消除大平面色带）、
以及按方块类型的程序化纹理：木板条纹、砖块错缝、铜矿杂斑、雪/沙顶面变亮、
星晶呼吸脉冲（`performance.now()` 驱动）、灯笼关闭态变暗等。

### 3.4 特殊方块网格

| 生成器 | 方块 | 要点 |
| --- | --- | --- |
| `pushWindow` | 7 木框窗 | 木框 + 十字玻璃芯，按朝向自适应 |
| `pushBookshelf` | 24 书架 | 5 本彩色书 + 层板 |
| `pushRug` | 25 地毯 | 双层薄盒（非固体） |
| `pushFireplace` | 26 壁炉 | 炉膛随 `fireplaceOn` 换色并登记点光源 |
| `pushFence/pushPot/pushLadder` | 27/28/29 | 栅栏横杆、花盆花朵、爬梯横档 |
| `pushCatCushion` | 30 猫垫 | 双色软垫 |
| `pushMailbox` | 33 信箱 | 旗子随「今日是否有新信」升降（`dayCount > mailDay`） |
| `pushPlacedDoor` | 8 木门 | 薄板门 + 门把；**主门**(11,1..2,15) 不画静态门，由 `drawDoor()` 按开合角旋转绘制 |

## 4. 相机设计

- **三种模式**（F5 循环）：0 第一人称；1 第三人称背面（**默认**）；2 第三人称正面（观察用，
  禁挖掘/放置）。`cameraMode` 存档。
- **肩位切换**（V）：第三人称时镜头沿右向量偏移 ±0.48。
- **防穿墙**：`clippedCamera()` 从眼点向目标位置步进采样（步长 2.5%），遇实心方块即截断；
  实际位置再做 18% 指数平滑，兼顾稳定与跟手。
- **FOV 动态**：疾跑/飞行加速时 `cameraFov` 平滑放大 12%（速度感反馈）。
- **缩放**：第三人称 Shift+滚轮 / 双指捏合，距离 2.2–6。

## 5. 玩家物理

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 碰撞体 | 半径 0.28 × 高 1.72 的 AABB | `collides()` 扫描覆盖到的所有体素 + 家具碰撞 |
| 移动 | 走 3.25 / 疾跑 5.0 / 飞 5（Ctrl 8）格每秒 | 逐轴移动，撞墙时另一轴不受影响 |
| 重力 | 18 格每秒²；跳跃初速 6.5（跳高约 1.17 格） | 下落时可被轨道面接住 |
| 飞行 | F 切换；空格升 / Shift 降 | 高度上限 `MAX_BUILD_HEIGHT+10`，掉出世界底部自动重置 |
| 轨道面站立 | `trackLandingHeight()` | 下落时在附近轨道列中采样轨面高度，允许站上轨道（坡道/弯轨可走） |
| 视线 | `raycast()` 步长 0.035，触达 6 格（飞行 12） | 返回命中方块 + 可放置邻格 |
| 掉落保护 | `player.y < BEDROCK_Y+.35` → `resetGame()` | 防止挖穿基岩后悬空 |

非固体类型（`isSolidType` 排除）：水 18、地毯 25、花盆 28、木梯 29、猫垫 30、轨道 37。

## 6. 世界生成

### 6.1 区域布局（`buildWorld()`，全新世界）

```
Z↑
0    ┌──────────────┬──────────────┬──────────────┬──────────────┐
     │  原始林区     │   河东林地    │   北境雪原    │  外域(湖/路)  │
     │  小屋(4..16,  │  蜿蜒河流+   │  雪松+冰屋    │              │
     │   2..15)     │  营地(39..45,│  (53..59,    │              │
     │  矿洞(22..30,│   25..31)    │   8..14)     │              │
     │   23..30)    │              │              │              │
64   ├──────────────┴──────┬───────┴──────────────┴──────────────┤
     │  南部沙漠+绿洲       │           外域扩展区                  │
     │  (17..47, 50..62)   │   大湖(87,81)·绿洲(115,111)·长路      │
127  └─────────────────────┴───────────────────────────────────────┘
     0                64                                127  →X
```

- **小屋**：13×14 木构两层（含阁楼 `buildLoft`）、门廊、菜园、猫角、信箱；
  屋内细节（床/书架/地毯/厨房）由 `buildHouseDetails()` 生成。
- **地下**：`undergroundDepthType(x,y,z)` 用整数哈希（`Math.imul` 混合 x/z/深度）
  决定泥土 35 / 石头 3 / 铜矿 20 的分布；y=−11 铺基岩 36。深挖有矿道层次感。
- **外域**（64..127 区域）由 `buildOuterWorldFeatures()` 生成：雪原/沙漠/岩石地表哈希、
  两大水域、三条延伸道路、成排树木、云块与边界树篱。
- **确定性**：所有随机来自坐标哈希（`outerWorldHash`），同坐标永远同结果——
  这是客户端与服务器迁移一致性的基础（见 06）。

### 6.2 生成与迁移复用

同一组 build 函数同时服务于「新世界生成」与「旧存档版本迁移」：
迁移时传 `migrating=true`，只做增量补齐（不覆盖玩家已有改动），并拆除旧边界树篱。
详见 [06-数据与存档设计](06-数据与存档设计.md)。

## 7. 环境模拟

### 7.1 昼夜与时间

- `worldTime` 0–24 循环，速率 `0.065 小时/秒` → **一天约 6 分 9 秒**。
- 跨零点时 `dayCount++`：触发鱼群繁殖、信箱新信判定、小猫礼物刷新、整图重建与存档。
- guest 端时间不自增，由主机 `environment` 消息（1Hz）驱动。

### 7.2 天气

- `weatherTimer` 倒计时切换晴/雨：雨天持续 28–50s，晴天 55–100s。
- 北境（x>48 且 z<22）下雨显示为**雪**（粒子形态、脚步声、提示语均不同）。
- **避雨判定** `isWeatherSheltered()`：屋内/门廊下/矿洞/营地/冰屋内，或头顶任意实心方块
  （`hasRoofAbove` 向上扫描）。避雨时天气粒子隐藏——玩家自然学会「下雨回家」。

### 7.3 氛围生物（纯视觉）

夜间：萤火虫（18 个固定点位周围游动发光）；白天：蝴蝶（8 个点位，翅膀开合动画）；
雨天隐藏。壁炉点燃时烟囱冒烟（4 团循环上升的渐变盒）。

## 8. 音效设计

全部音效由 `tone(freq, dur, type, volume)` 即时合成（正弦/方波/锯齿/三角），
受全局 `masterVolume` 与开关控制：

- **反馈分层**：UI 提示（420–920Hz 短音）、放置（145Hz 方波）、挖掘完成（105Hz）、
  脚步（按方块类型 42–150Hz 差异化）、成就解锁（双音上行）、列车发车/到站（双音和弦）。
- **距离衰减**：列车通过声、鸣笛轨等仅 14 格内播放。
- **组合音**：重要事件用 `setTimeout` 串联两个音（如开门 280→190Hz）模拟「咔哒」。

## 9. HUD 与界面系统

### 9.1 常驻 HUD

- **任务卡**（左上）：主线进度条 + 阶段文案（`questStage` 0→3，完成变绿）。
- **状态条**（顶中）：时钟（☀/☾/☂/❄ + HH:MM）、星晶进度、生命（♥×5）、飞行/联机徽标。
- **导航罗盘**（`navHud`）：8 方向箭头 + 距离，指向当前导航目标（地标或轨道断口）。
- **小地图**（右上 160×160 canvas）：局部 32×32 / 全图两档（N 切换），
  地表着色 + 轨道网络叠加 + 规划路线高亮 + 实体点位。
- **热键栏**：11 格（数字 1–9、0、−），显示库存缩写（≥1000 显示 `1.0k`）。
- **动态提示**（`prompt`）：根据准星指向与距离，显示当前 E 键可做的事（门/宝箱/猫/轨道…）；
  **目标信息**（`targetInfo`）：指向物的详细状态（轨道类型/接通数/信号区间…）。
- **专用 HUD**：轨道模式条（形状/朝向/列车状态）、乘车条（速度/停靠/目的站）、
  轨道快捷面板（` 键呼出的 20 格积木选盘）。

### 9.2 面板体系

13 个模态面板共用一套模式：打开时 `paused=true` + 清空按键状态 + 释放指针锁，
关闭时按来源返回游戏或返回暂停菜单（`xxxReturnToPause` 标记）。
Esc 键按「模板预览 → 各面板 → 暂停」的固定优先级分派关闭。

### 9.3 大地图（Tab）

576×576 canvas 全图渲染：地表/植被/建筑着色、轨道网络彩色叠加（含站名标注）、
规划路线金色高亮、地标图标（未发现显示 ?）、导航虚线；点击设导航目标；
`mapLayer` 切换**地下勘探图**（Y −1..−10，U 键循环深度，铜矿橙色高亮）。

## 10. 输入系统

### 10.1 桌面

- **指针锁**：点击画面进入 Pointer Lock；`pointerlockchange` 检测到非主动退出时自动弹暂停。
  锁定失败时可按住拖动视角（`dragging` 兜底）。
- **关键绑定**（节选，完整表见暂停菜单帮助区）：
  - 移动 WASD/方向键 · 疾跑 Shift · 跳 Space · 飞行 F · 互动 E（Shift/Ctrl+E 为轨道扩展交互）
  - 挖掘按住左键 · 放置按住右键（连续铺轨）· 取样中键 · 滚轮切物品（Shift+滚轮缩放）
  - C 制作 · I 背包 · B 装修 · L 联机 · T 聊天 · K 轨道管理 · Tab 地图 · J 故事 · M/N 导航
  - 轨道：` 快捷模式（1–0 / Shift+1–9 / Shift+0 选 20 种积木）、R/Shift+R 换型、Q 旋转/坡向、
    X 停开、Shift+X 调速、Ctrl+X 换向、Y 收车、H 鸣笛、Alt+Q/R 旋转/替换、Alt+Z/Y 撤销/重做
- **防误触**：面板打开时屏蔽游戏键；输入框聚焦时仅响应 Esc/Enter。

### 10.2 触屏（`pointer:coarse` 或 ≤720px 启用）

- 左下十字键（WASD 映射）+ 右下动作钮（互动/放置/挖打/跳跃），`touch-action:none` 防滚动。
- 单指滑动转视角（灵敏度低于鼠标）、双指捏合调相机距离。
- 互动按钮在飞行模式下复用为「下降」。
- 布局适配：隐藏小地图/品牌、热键栏改 5 列两行上移、各面板单列化。
