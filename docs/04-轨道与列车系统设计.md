# 04 · 轨道与列车系统设计

> 这是本项目最复杂、也最有辨识度的子系统：一套「玩具外观、真实逻辑」的木质铁路网，
> 覆盖建造（吸附/模板/编辑）、拓扑（图结构/线路识别）、运营（信号/调度/巡线）
> 与安全（行人避让/净空/车距）四个层面。
> 相关代码集中在 `minicraft.js` 的轨道区段与 `interact()/place()` 的轨道分支。

## 1. 设计目标

1. **积木化**：轨道是「1×1 / 1×2 / 2×2 的积木」，儿童玩具式拼装，但接口有方向语义。
2. **自动辅助**：放置自动吸附对齐已有轨道；连续铺轨自动延伸；模板一键成网；
   寻路自动拨道岔、转向转盘。
3. **安全拟真**：自动闭塞信号、行人/障碍检测、车距控制、净空检查——
   列车「永远不会撞上任何东西」，只会礼貌地停下等待。
4. **可运营**：车站停靠时刻、自动巡线（地铁化）、多车 fleet、感应分流（自动化玩法）。
5. **可撤销**：单件放置、模板整套、整条线路、单件编辑，四级撤销/重做都有。

## 3. 数据模型

### 3.1 轨道件（`trackPieces[]`，29 个字段）

```js
{
  id, x, y, z, rot(0..3), shape,
  // 通用开关（按 shape 取用）
  rampRise,            // 坡道/弯坡轨：沿朝向上升/下降
  branch,              // 岔道轨：true=弯道
  stationStop, stationDwell(1|2|4|8), stationOrder, stationService, stationName,
  depotStop,           // 车库：自动入库
  signalGreen, signalMode(-1|0|1),
  powerMode(-1|0|1), trackLampOn,
  crossingMode(-1|0|1), oneWayForward, drawbridgeOpen,
  whistleOn, passCount,
  turntableAxis, turntableExit(0..3),
  detectorMode(0..3), detectorCount, detectorTargetId,
  lineName,            // 所属线路名（线路识别用，最长 18 字符）
}
```

轨道件在体素世界中同时以**方块 37** 占位（`rebuildTrackOccupancy()` 把每件轨道的
占用格写入 world），使射线检测/小地图/碰撞自然工作；真实状态单独存 `trackPieces`。

### 3.2 三重索引（`rebuildTrackGraph()`）

| 索引 | 键 | 值 | 用途 |
| --- | --- | --- | --- |
| `trackPortIndex` | `trackPortKey(p)` = `round(x×2),round(y×10),round(z×2)` | `[{piece, index}]` | **接口对接判定**：两个接口位置量化相等且方向相反 ⇔ 连通 |
| `trackCellIndex` | `"x,y,z"` | piece | 由体素坐标反查轨道件 |
| `trackColumnIndex` | `"x,z"` | `Set<piece>` | 水平列查询（玩家站轨道、附近轨道） |

接口坐标按半格量化（×2）允许 1×2 与 2×2 积木的端点自然对齐；y ×10 保留坡道高差精度。

### 3.3 几何原语

- `trackCells(t)`：该件占用的体素格（坡道跨 y 与 y+1，弯坡轨跨 2×2×2）。
- `trackPorts(t)`：接口列表 `{x, y, z, index, dir}`；方向 `dir` 为世界四向（0 南 /1 东 /2 北 /3 西）。
- `trackCenter(t)`：局部原点（旋转/平移变换基准）。
- `trackLocalToWorld(t, lx, lz, dy)`：局部坐标 → 世界坐标（绕中心旋转 `rot×90°`）。

## 4. 拓扑与线路识别

### 4.1 连通判定

```
connectedTrackPort(piece, index):
  在 trackPortKey 相同的候选中，找「另一件轨道、接口方向 = 本接口方向 + 2 (mod 4)」者
```

即：**位置重合 + 方向相对**才算接通。这保证了单向轨、错向对接等情形的正确语义。

### 4.2 路由规则（`trackRouteExit(piece, entry)`）

| shape | 规则 |
| --- | --- |
| 直行类（直/弯/坡/车站/信号/桥/隧道/车库/动力/灯光/道口/单向/升降桥/鸣笛/感应） | 进 0 出 1，进 1 出 0 |
| 交叉轨 | 对穿：`(entry+2)%4` |
| 岔道轨 | 进 0 → 出 `branch ? 2 : 1`；进侧口 → 出 0 |
| 旋转轨 | 出口 = 预选出口 `turntableExit`；若从出口进入则对穿 |
| 终点挡块 | 无出口（列车折返） |

### 4.3 路径参数化（`trackPathRaw(piece, entry, exit, u)`）

把每条「入口→出口」表达为 u∈[0,1] 的三维曲线，供列车推进与地图绘制共用：

- 直行类：入口/出口端点线性插值；
- 弯轨/弯坡轨/岔道弯支：**二次贝塞尔**（控制点取格子中心），长度 ×1.12 弧长修正；
- 坡道：端点 y 差线性；
- 终点挡块：折返抛物（走到 20% 处返回）；
- 旋转轨横穿：两段折线经过中心；纵穿（进→预选出口）也经中心。

### 4.4 线路识别（`trackNetworks()`）

对轨道件做**DFS 连通分量**（沿接通的接口扩散），每个分量即一条「线路」，缓存于
`trackNetworkCache`（拓扑变化时置空）。线路聚合展示：

- 件数、总长度（按路径长度累加）、高度范围、断口数（未接通接口数）；
- 车站序列（按 `stationOrder` 排序）、巡线车站数、信号数、净空不足件数；
- 线路名：取成员中最小的自定义 `lineName`，否则自动「线路 N」；颜色 = id 哈希色相。

## 5. 列车模拟

### 5.1 车队模型

- **主列车** `trackTrain`（可乘坐、可挂 0–3 节客车厢、猫可乘）+ **副列车** `extraTrains`（≤3），
  全图合计 ≤4 列。副列车可随时「接管」升级为主列车（原主列车降级为副列车换位）。
- 每列状态：所在件 `pieceId`、进/出口 `entry/exit`、件内进度 `t∈[0,1]`、当前/巡航速度、
  累计里程 `distance`、停靠倒计时 `wait`、各类一次性事件旗标。

### 5.2 运动积分（每帧）

```
speed → 目标速度（限制栈取最小，见 5.3）；加/减速平滑（加速 1.25/s，减速 3.4/s，避让行人 8/s）
distance += speed·dt
沿当前件推进 t，跨件时经 connectedTrackPort 换轨并重算 entry/exit/t
到达断口（无下一件）→ 原地折返（entry/exit 互换，t 翻转）
```

跨件瞬间播放车轮接缝音（`trainJointSound`，14 格内）。

### 5.3 速度限制栈（`trainPieceSpeedLimit`）

最终速度 = min(巡航速度, 各项限制)，全部为**距离比例减速**（提前平滑降速而非急停）：

| 限制 | 主列车 | 说明 |
| --- | --- | --- |
| 弯轨 | ≤1.15 | 副列车 1.05 |
| 弯坡轨 | ≤0.9 | |
| 岔道轨 | ≤1.0 | |
| 坡道上/下坡 | ≤1.0 / 1.3 | 按俯仰角 |
| 道口 / 隧道 / 车库 | ≤0.9 / 0.82 / 0.58 | 隧道与车库属于「礼仪限速」 |
| 红灯信号 | t<0.34 时 `(0.34−t)×3.5`；t≥0.34 强制 0 | 停车线在件内 34% 处（§7） |
| 车站停靠 | 未服务且 t<0.5 时 `(0.5−t)×3.2` | 停车位在件内 50% 处 |
| 障碍（净空） | `(距离−0.08)×2.4` | 前方件被方块压顶 |
| 行人 | `(距离−0.38)×1.8` | §5.6 |
| 车距 | `<0.82`→0；`<1.7`→0.28；`<2.4`→0.65 | 对全车队（含车厢）欧氏距离 |

### 5.4 件内事件（按 t 阈值一次性触发）

| t | 事件 |
| --- | --- |
| 0.34 | 信号红灯：刹停 + toast 提示原因（区间占用/需修复） |
| 0.5 | 车站：停靠 `stationDwell` 秒（目的站则停车待命）；车库：入库停车（`running=false`） |
| 0.5 | 动力轨：加速档巡航=2.0 / 制动档 0.8；鸣笛轨：鸣笛 + 计数；感应轨：触发（§9） |

跨件时清除 `stationServed/powerServed/whistleServed` 一次性旗标。

### 5.5 车厢跟随（`trainTrail`）

车厢不能简单按主车姿态平移（弯道上会脱轨），因此维护**轨迹历史**：
主车每 0.025 格里程记录一位姿，车厢按「落后 0.92 / 1.76 / 2.60 格里程」在历史上
插值取位姿（`trainTrailPose`），弯道表现自然。缓存仅保留最近 4 格里程。

### 5.6 行人安全（设计亮点）

`trainPedestrianDistance()`：从列车当前位置沿前进方向最多扫描 4 件轨道，
每件路径 24 采样点，检测「水平距离 ≤0.58 且高差 <1.15」的行人
（本地玩家 + 所有非乘车/非飞行远端玩家）：

- 距离 <0.48 → 完全停车并置 `pedestrianWaiting`，车顶显示脉冲警示牌；
- 首次进入等待 → toast「轨道前方有人 · 列车正在安全停车」；
- 恢复后以 8/s 的减速率快速重启。

### 5.7 乘坐体验

- 上车（距车 <1.45 按 E 或对轨道交互）：玩家位姿绑定列车，**视角随弯道自然旋转**
  （`syncTrackRider` 按航向差增量旋转 yaw，pitch 随坡度）；
- HUD 显示：状态（停靠/红灯/上坡/巡航/目的站）、实时速度/巡航速度；
- H 鸣笛、Ctrl+X 换向、Y 收车、E/空格下车（下车自动寻找车侧空位，避免卡墙）。

## 6. 调度与寻路

### 6.1 BFS 寻路（`planTrackRoute`）

- 状态空间 = `(piece, entry)`；从列车当前件出发（可双向起算，支持倒车发车）；
- 扩展规则按 shape：岔道轨两个分支都入队；旋转轨枚举 4 个出口（被占用时仅当前出口）；
  终点挡块不可折返但允许作为目标进站；
- 找到目标车站后**回放路径**：顺路自动拨正道岔（`branch`）、预转向转盘（`turntableExit`），
  并生成 `routePlan`（≤256 步）用于地图金色高亮与 3D 引导线。

### 6.2 发车与自动巡线（`setTrainDestination` / `autoService`）

- 「前往」任意车站：跨线路时自动把主列车调度到目标线路代表站再寻路；
- **自动巡线**：线路中 ≥2 座开启 `stationService` 的车站即可开启；
  列车按 `stationOrder` 顺序循环发车（到站 → 停靠 dwell → 下一站），
  玩家随时可「前往」打断、或关闭巡线（当前程结束后停车）。
- 车站顺序可在管理面板 ↑↓ 调整（`moveStationOrder` 重写 stationOrder）。

### 6.3 车队管理

每条线路可「＋列车」（自动选择远离既有车的可放置件，安全间距不足则拒绝）；
副列车可停车/启动/收回/接管。全部状态进入存档与联机同步。

## 7. 信号系统（自动闭塞）

### 7.1 三种模式（E 循环）

`signalMode`：0 自动（默认）/ 1 强制绿灯 / −1 强制红灯。

### 7.2 自动闭塞判定（`trackSectionStatus`）

从信号轨沿行进方向最多扫描 24 件，遇到第一个「不安全」即红灯：

| 检查 | 结果 |
| --- | --- |
| 前方断口 | 不安全（除非是终点挡块 →「终点保护」） |
| 单向轨禁行 / 升降桥开启 | 不安全 |
| 前方件净空不足（被方块压顶） | 不安全 |
| 前方件有列车/车厢占用 | 不安全（「区间有列车」） |
| 前方件轨道上有行人 | 不安全 |
| 回到本信号（环线） | 安全（「环线保护」） |
| 遇到下一座信号 | 安全（闭塞区间到此为止） |
| 遇到车站/车库/终点 | 安全（「车站/车库/终点保护」） |

即**闭塞分区 = 本信号到下一个信号/车站/终点之间**，同区段只允许一列车——
双站环线模板据此可实现真正的追踪运行。

### 7.3 可视化

- 信号轨双面灯色实时绘制（`drawSignalLights`）；
- 瞄准信号轨时：地面红/绿引导线覆盖整个闭塞区间 + 末端信标（`drawSignalSectionGuides`），
  提示文案给出具体原因（`signalInfoText`，如「自动闭塞 · A端红 · 区间有列车」）。

## 8. 道口与升降桥

- **道口**（`crossingShouldClose`）：任意列车/车厢进入中心 2.8 格 → 栏杆动画落下（5/s 插值），
  通过后抬起；`crossingMode` 可强制开/关。
- **升降桥**（`drawbridgeBusy`）：桥上有车时禁止升起；升起后 `trackAllowsEntry` 拒绝通行
  （列车与信号均识别），动画 2.8/s；两端绘制桥台，闭合角 <0.08 才恢复通行。

## 9. 感应轨（自动化玩法）

`detectorMode` 四档（E 循环）：

| 模式 | 行为 |
| --- | --- |
| 0 仅计数 | 通过 +1，近处播放提示音 |
| 1 报站提示 | 计数 + toast「列车通过感应轨 · 第 N 次」 |
| 2 岔道触发 | 通过时拨动绑定岔道（直行⇄弯道交替）→ 自动分流 |
| 3 转盘触发 | 通过时把绑定旋转轨出口顺时针转 90° → 环形巡游 |

- **目标绑定**：自动选择 8 格内最近的同类目标；Shift+E 在 32 格内候选中循环绑定
  （`detectorTargetCandidates` 按距离排序，含显示名「岔道 #id」）。
- 联机下仅主机执行真实切换（`triggerDetector` 对 guest 只做视觉脉冲），
  结果经 shared 状态同步——保证列车与感应的因果一致。
- 地图与 3D 中绘制感应轨 → 目标的链路线（`drawDetectorLinks`）。

## 10. 建造与编辑

### 10.1 放置吸附（`trackPlacementPreview`）

以准星落点为锚，在 **±2 格邻域 × 4 朝向**枚举候选件：
- 占用格必须全空且在界内；
- 必须至少接通 1 个已有接口；
- 评分 = 接口数×100 − 中心偏距 − 朝向偏转；取得分最高者。

无任何可吸附时退化为玩家朝向的直放。**幽灵预览**实时绘制（绿=可放/红=受阻）。

### 10.2 连续铺轨（按住右键）

`extendTrackChain()`：从上一件出发，沿其**最远的未接通接口**与玩家期望朝向，
搜索下一件可吸附位置（枚举接口邻域），实现「按住右键一路铺过去」；
每 0.13s 一件，松开时统一存档。

### 10.3 原地编辑（Alt 快捷键）

- **Alt+Q 旋转**：瞄准已铺轨道原地转 90°（坡道类 Alt+Q 循环升/降向）；
- **Alt+R 替换**：原地换成当前选中的积木类型，**继承可兼容的状态字段**
  （站名、信号模式、感应绑定等按类型保留）；
- 撤销/重做各 30 步（`trackEditUndo/Redo`，快照 before/after）；
- 目标件被列车/车厢占用时拒绝编辑（`trackPieceBusy`）。

### 10.4 其他建造辅助

- 中键**取样**：复制瞄准轨道的类型/朝向/坡向到当前选型；
- R/Shift+R 循环 20 种类型；Q 旋转朝向（坡道类 Q 切升降）；
- `` ` `` 轨道快捷模式：数字键直选 20 种积木（1–0 前 10，Shift+1–9/0 后 10）。

## 11. 模板系统

- **13 套内置模板**（`TRACK_TEMPLATES`）：经典环线、双站往返、高架观景、灯光庆典环线、
  暖灯穿山、自动闭塞双站环线、三股调车场、四向转盘枢纽、感应分流体验线、双车库调度场、
  双桥湖畔观光、感应转盘巡游站、森林蛇形探险线——每套都是「一个教学关卡」，
  引导玩家理解对应机制。
- **自定义蓝图**：任意线路可「保存模板」（≤96 件，规格相对原点归一化），
  上限 8 份，可删除；模板继承站名/信号模式/感应绑定等状态。
- **摆放流程**：选模板 → 在玩家前方 8 格搜索可用位置（半径 ≤6 螺旋扩张，`locateTrackTemplate`）
  → 幽灵预览（Q 旋转，占用变红提示）→ 左键确认（检查库存、被占时自动迁移附近）→ 整套撤销入 `buildHistory`。
- 模板旋转 = 对每件规格做中心旋转 + `rot` 偏移（`transformTemplatePieces`）。

## 12. 管理面板（K）

面板按层级组织：

```
▤ 轨道线路管理
├── 轨道积木目录（20 种，点击选型）
├── 轨道模板（内置 + 我的蓝图）
├── 概要（线路数 / 总件数 / 列车位置）
├── 列车队列（主列车车厢 ± ；副列车 接管/停车/收回）
├── 线路列表（每条线路一张卡片）
│    ├── 名称编辑（重命名整线）
│    ├── 统计：件数/长度/车站/信号/净空/高度/断口
│    ├── 车站行：↑↓ 巡线序 · 改名 · 停靠时长(1/2/4/8s) · 巡线开关 · 前往
│    └── 操作：调度火车 · 自动巡线 · 检查断口 · ＋列车 · 保存模板 · 拆除线路 · 地图查看
└── 底部：Alt+Z/Y 撤销重做 · Y 收回列车 · 返回
```

- **检查断口**：把导航罗盘指向该线路最近的未接通接口，并在地图上高亮——
  「断口」是玩家最常需要定位的拓扑缺陷。
- **拆除线路**：二次确认（4s 武装窗口）；有列车/车厢占用时拒绝；
  拆除件数返还库存（上限截断），并写入可撤销的 `restoreTracks` 记录（Z 恢复整线）。

## 13. 安全机制汇总

| 风险 | 防护 |
| --- | --- |
| 列车撞行人 | 前视 4 件 ×24 采样检测，<0.48 停车 + 警示牌 |
| 列车撞障碍/互相追尾 | 净空检测 + 车距限制栈（0.82 格硬停） |
| 红灯冒进 | 停车线 t=0.34 强制 0 速 |
| 桥上起桥 | `drawbridgeBusy` 拒绝 |
| 旋转轨转动时被车占用 | `trackPieceBusy` 拒绝 |
| 编辑/拆除伤及运行中列车 | 编辑与整线拆除均检查占用 |
| 拆轨拆走列车脚下件 | 列车自动收回并提示 |
| 感应轨在联机下双端执行 | 仅主机执行，状态经同步传播 |
