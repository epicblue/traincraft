# MINICRAFT · 林间小屋 — 设计文档

本目录存放项目的设计文档（design docs），与代码、测试、运维说明相互独立。
文档基于当前代码现状编写（客户端资源版本 `?v=41`，存档格式 `v3`，世界版本 `worldVersion 13`）。

## 项目速览

| 项目 | 内容 |
| --- | --- |
| 名称 | MINICRAFT · 林间小屋（仓库：traincraft） |
| 定位 | 零依赖、浏览器直开的体素沙盒游戏 + 木质铁路模拟，带「归家」叙事 |
| 客户端 | 原生 HTML / CSS / JavaScript（WebGL 1.0），单文件游戏运行时，无任何 CDN / 框架 / 构建步骤 |
| 服务端 | Python 3.10+ / aiohttp，静态托管 + WebSocket 房间服务器，每房间最多 8 人 |
| 备用联机 | WebRTC DataChannel 手动点对点（无需服务器） |
| 存档 | localStorage 自动保存 + gzip 备份导入导出；服务器端房间持久化 |
| 测试 | Node.js 客户端逻辑回归 + Python 服务器回归（`tests/`） |
