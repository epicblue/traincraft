# 07 · 测试与质量保障

> 本项目没有常规单元测试框架，而是采用「**可执行规格**」式回归测试：
> 断言代码结构与关键算法的既有行为，防止重构/加特性时无声破坏。
> 运行说明见 [tests/README.md](../tests/README.md)。

## 1. 测试策略

| 原则 | 做法 |
| --- | --- |
| 无浏览器依赖 | 客户端测试用 Node 直接执行从 `minicraft.js` 中**提取的纯函数**（`extractFunction`），不启动 DOM/WebGL |
| 结构即契约 | 项目结构测试锁死「无内联脚本/样式、单 IIFE、无外链、版本号一致、DOM id 完整」等架构约束 |
| 算法即规格 | 轨道占用/接口/寻路/信号等核心算法用固定输入输出断言（含模板四向旋转连通性） |
| 双端一致性 | 服务器迁移测试断言具体坐标的方块值，确保 Python 迁移与 JS 迁移逐块一致 |
| 隔离与清理 | 所有服务器/迁移测试用临时目录，不触碰真实 `server_data` 与玩家存档 |

依赖：Python 3.10+（含 aiohttp）与 Node.js 18+。

## 2. 测试组成（`tests/run_all.py` 四阶段）

| 阶段 | 命令 | 内容 |
| --- | --- | --- |
| 1. 客户端语法 | `node --check assets/minicraft.js` | 单文件可解析 |
| 2. 客户端逻辑回归 | `node tests/client_regression.js`（758 行） | 轨道/列车/模板/信号等纯逻辑 |
| 3. 服务器语法 | `python -m py_compile server.py` | — |
| 4. 结构与服务器回归 | `python tests/project_server_regression.py`（242 行） | 结构守护 + gzip + 房间/迁移/校验 |

入口：`python3 tests/run_all.py`、`./tests/run_regression.sh`、`tests/运行完整回归测试.bat`。

## 3. 项目结构守护（`project_server_regression.py::test_split_project_integrity`）

- 四个核心文件存在且 >100 B；`index.html` **<50 KB** 且不含 `<style>`/`<script>` 内联块；
- HTML 引用 `assets/minicraft.css?v=` 与 `assets/minicraft.js?v=`，且 `?v=N` 与 JS 内
  `trackFeatureVersion` 一致（发版缓存联动）；
- CSS 无 `http(s)://` 外链；JS 恰好一个 IIFE；
- `index.html` 中被 `getElementById` 引用的 id ≥200 个且**全部存在**（防 DOM 改名漏改）。

## 4. 客户端逻辑回归覆盖（`client_regression.js`）

按 `tests/README.md` 的清单（节选归类）：

1. **积木目录**：20 种轨道固定顺序、尺寸与旧存档索引兼容；
2. **模板系统**：13 套内置模板在**四个旋转方向**的占用与接口连通（含双桥、感应转盘、蛇形线）；
3. **旋转轨**：四向出口、中心转向路径、方向标签、寻路、图标、`Shift+8` 快捷键、
   交互锁定、车站寻路自动预转向；
4. **感应轨**：计数、报站、动态脉冲、`Shift+E` 绑定、岔道/转盘触发、联机主机权限；
5. **蓝图**：线路保存为个人模板、状态清理、持久化、重复摆放、8 份上限、删除；
6. **整线拆除**：二次确认、列车占用保护、库存返还、Z 整线恢复；
7. **车站**：1/2/4/8s 停靠、Shift+E 时长、Ctrl+E 巡线开关、↑↓ 顺序、蓝图保存；
8. **模板预览**：幽灵预览、旋转、位置被占迁移、确认、库存与整套撤销；
9. **信号**：自动闭塞方向、保护区间追踪、3D 引导、列车占用、行人与净空检测；
10. **可站立表面**：直/弯/坡/升降桥/旋转轨的表面高度与空间索引。

## 5. 服务器回归覆盖（`project_server_regression.py`）

- **备份 gzip 往返**（`test_backup_gzip_roundtrip`）：压缩 → 魔数 `1f 8b` → 解压还原相等；
- **世界迁移**（`test_server_world_migration`）：构造旧版房间 → 迁移后断言
  `worldVersion==13`、界外基岩、外域水体 `(87,0,81)==18`、延伸道路、旧浅层基岩被打开、
  挖掉的洞不被回填、树篱拆除、房间文件落盘且无 `.tmp` 残留、持久化 JSON 版本正确、
  方块总量 >19 万；
- **消息校验**（`test_server_message_validation_async`）：真实 WebSocket 客户端连入，
  断言越界坐标（x=128、y=−12）被丢弃、合法写入生效、无权 guest 收到 `permission`、
  猫命令数值被清洗（stayX 钳制到 128）等。

## 6. 修改代码时的检查清单

提交前建议自检：

1. `python3 tests/run_all.py` 全绿；
2. 改了 DOM 结构 → 确认所有 `getElementById` 引用仍存在（结构测试会抓）；
3. 改了 `TRACK_SHAPES` 顺序/字段 → 旧存档兼容性与模板规格测试会失败，需同步更新
   迁移逻辑与测试；
4. 改了世界生成/迁移 → **必须同步改 `server.py` 的 Python 复刻**并更新迁移断言；
5. 改了消息协议 → 双端（客户端 `handleNetworkMessage` / 服务器 `process`）同步，
   并考虑旧客户端兼容；
6. 发版 → `index.html` 的 `?v=` 与 JS 的 `trackFeatureVersion` 同时 +1；
7. 手工冒烟：开门 → 宝箱 → 铺环线 → 放车巡线 → 存档重载 → 双机联机放置方块。

## 7. 质量属性现状与改进方向

| 属性 | 现状 | 方向 |
| --- | --- | --- |
| 正确性 | 核心算法回归覆盖较高 | 玩法层（猫/钓鱼/装修）尚无自动化断言，可继续提取纯函数测试 |
| 性能 | 无自动化性能测试；分块剔除 + 三档画质 | 可加首帧构建/网格重建耗时基准 |
| 兼容性 | WebGL 1.0 + mediump，覆盖面广 | 无真实浏览器矩阵（依赖用户反馈） |
| 可观测性 | 服务器仅控制台日志 | 可加房间事件结构化日志 |
| 安全 | 输入校验完备（局域网威胁模型） | 公网部署建议反代 + TLS + 限速 |
